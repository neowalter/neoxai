### [MNE-Python 拒绝「对复数 Welch 系数做平均」这种无意义组合](https://github.com/mne-tools/mne-python/pull/14498)
*MNE-Python Rejects Averaging Complex Welch Coefficients*

**简介：** MNE-Python 合并 #14498（修 #14495）：当 Welch 指定 **`output="complex"`** 又要求 **`average="mean"`/`"median"`** 时**直接报错拒绝**。原因很本质——各段的傅里叶系数**相位不一致**，把它们平均后再平方得到的功率，**不等于**各段功率的平均；此前这个组合能跑通，只是返回一张没有物理意义的谱。这类「能算但算错」的 API 组合是静默错误的高发区，尤其在做相位敏感分析（相位锁值、跨试次相干、复数谱）时，结果看起来完全正常。建议升级后检查既有脚本是否踩过这个组合，并改用对功率做平均、或保留 per-segment 的复数谱自行处理。

**Brief:** MNE-Python merged #14498 (fixing #14495) to raise an error when Welch uses output="complex" with average="mean" or "median": per-segment Fourier coefficients have inconsistent phases, so power from the average is not the average of power. The combination used to return a physically meaningless spectrum silently — a classic silent-error pairing for phase-sensitive analyses.

- #14498（修 #14495）：当 Welch 指定 `output="complex"` 又要求 `average="mean"`/`"median"` 时**直接报错**——各段傅里叶系数**相位不一致**，平均后的功率不等于功率的平均。
- 这是一个「能算、但算出来没有物理意义」的组合，此前会静默返回误导性谱。
- 对做相位敏感分析（相位锁值、跨试次相干、复数谱）的团队，这条校验能把「结果不对但流程不报错」挡在入口。

- It was a computable but physically meaningless combination that previously returned a misleading spectrum silently.
- Teams doing phase-sensitive work (phase locking, cross-trial coherence, complex spectra) get that failure blocked at the entry point.
