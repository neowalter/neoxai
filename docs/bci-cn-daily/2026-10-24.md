**Brief:** Eelbrain merged #210 giving Factor-valued trigger events a stable, content-derived code. That decides whether event codes stay identical across re-runs: if coding depends on insertion order, condition-based epoching drifts and misaligns across sessions or subjects, usually without an error. Teams building event-related design matrices should compare event codes and epoch counts after upgrading.

- #210：对值为 Factor（类别型）的触发事件改用**稳定、由内容派生**的编码，避免每次运行得到不同的事件码。

- #210 gives trigger events whose values are Factor (categorical) a stable, content-derived code instead of codes that can change between runs.
