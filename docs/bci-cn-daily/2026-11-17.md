**Brief:** hnn-core merged #1400: the newer spike_train drive never pre-sorted spikes at creation, unlike every other drive type, so unsorted external spike data crashed simulations (reproduced via pytest). The fix sorts consistently and adds regression tests — a textbook new-feature inconsistency where conventions live only in old code paths.

- #1400：较新的 `spike_train` 驱动类型**创建时没有预排序脉冲**，喂入未排序数据时模拟直接崩溃（pytest 实测触发）。

- #1400 fixes the relatively new spike_train drive type, which never pre-sorted spikes at creation; unsorted data crashed simulations outright, as pytest runs showed.
- The fix sorts this drive's spikes exactly like all other drive types and adds regression tests.
- A classic inconsistency introduced by a new feature: an old-path convention silently missing from the new one, exploding on external spike data.
