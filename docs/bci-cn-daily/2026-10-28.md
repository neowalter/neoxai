### [BrainFlow 修 BLACKMAN_HARRIS 窗口：用的是 Nuttall 系数](https://github.com/brainflow-dev/brainflow/pull/868)
*BrainFlow Fixes BLACKMAN_HARRIS: It Was Using Nuttall's Coefficients*

**简介：** BrainFlow 合并 #868，修一个不易察觉的 DSP 错误：`DataFilter.get_window(BLACKMAN_HARRIS, n)` 返回的**并不是 Blackman-Harris 窗**——实现里用的 `0.355768, 0.487396, 0.144232, 0.012604` 是 **Nuttall「连续一阶导数」四项窗**的系数（A. H. Nuttall, 1981）。窗函数直接决定频谱泄漏与旁瓣衰减：系数错意味着你算出的 PSD、以及基于窗口的滤波结果都带着「另一种窗」的偏差，而代码不会报任何错。对用 BrainFlow 做在线频谱、睡眠纺锤波检测或带通滤波的团队，建议升级后用纯正弦做一次自检（看主瓣宽度与旁瓣水平），并把既有分析中依赖窗口的部分核对一遍。

**Brief:** BrainFlow merged #868 fixing a subtle DSP error: DataFilter.get_window(BLACKMAN_HARRIS, n) did not return a Blackman-Harris window — its coefficients 0.355768, 0.487396, 0.144232, 0.012604 belong to Nuttall's continuous-first-derivative window (1981). Windows govern leakage and sidelobes, so wrong coefficients bias PSD and windowed filters silently.

- #868：`DataFilter.get_window(BLACKMAN_HARRIS, n)` 返回的并不是 Blackman-Harris 窗——实现里用的 `0.355768, 0.487396, 0.144232, 0.012604` 是 **Nuttall 的连续一阶导数四项窗**系数（Nuttall, 1981）。
- 窗函数决定频谱泄漏与旁瓣衰减；系数用错会让 PSD/滤波结果与「你以为的窗」产生的偏差，且不会报错。
- 对用 BrainFlow 做在线频谱或带通滤波的团队，建议升级后重跑一次基准信号（如纯正弦）核对旁瓣与主瓣宽度。

- #868: DataFilter.get_window(BLACKMAN_HARRIS, n) did not return a Blackman-Harris window — its coefficients 0.355768, 0.487396, 0.144232, 0.012604 are Nuttall's continuous-first-derivative four-term window (Nuttall, 1981).
- Window choice sets spectral leakage and sidelobe attenuation, so wrong coefficients bias PSD and filter results with no error raised.
- Teams using BrainFlow for online spectra or band-pass filtering should re-check mainlobe width and sidelobes on a known sine after upgrading.
