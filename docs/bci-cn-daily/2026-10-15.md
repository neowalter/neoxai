### [MontageFlow：把生成的速度场投影到零空间，保证生成 EEG 物理有效](https://github.com/sudarshanregmi/MontageFlow)
*MontageFlow Projects Generated Velocity Fields onto a Null Space for Physically Valid EEG*

**简介：** 新建仓库 MontageFlow（2026-10-14，对应 arXiv:2610.14507）给出一个「物理有效」的 EEG 生成模型实现：编码器把 EEG 窗口压成全局隐变量，解码器依据当前流状态、流时间、类别标签与扰动隐变量预测速度场；训练完成后用类别条件的 rectified-flow 先验替换编码器做生成。核心设计是把预测速度**投影到 ker A**（A 为与蒙太奇相关的线性算子零空间），推理时对高斯源做同样投影——生成结果在数学上被约束为满足蒙太奇/物理一致性，而非仅靠后处理。仓库结构完整（configs/、montageflow/、scripts/、tests/），权重发布在 Hugging Face，数据取 Temple University Hospital EEG 语料。

**Brief:** Created 2026-10-14 (arXiv:2610.14507), MontageFlow implements physically valid EEG generation: an encoder maps a window to a global latent and a decoder predicts a velocity field from flow state, flow time, class label and perturbed latent; a class-conditional rectified-flow prior then replaces the encoder. Velocities are projected onto ker A of the montage operator, hard-constraining outputs.

- 方法：编码器把 EEG 窗口映射为全局隐变量，解码器输入当前流状态、流时间、类别标签与扰动隐变量来预测速度场；训练后用以类别为条件的 rectified-flow 先验替换编码器生成。
- 关键约束：预测速度被投影到 ker A（A 即与蒙太奇相关的线性算子零空间），推理阶段的高斯源同样投影，从而保证生成信号满足物理/蒙太奇一致性。
- 仓库为 PyTorch 实现（configs/、montageflow/、scripts/、tests/），权重发布在 Hugging Face；数据使用 Temple University Hospital EEG 语料（TUAB v3.0.1 等）。

- Method: an encoder maps an EEG window to a global latent; the decoder takes the current flow state, flow time, class label and a perturbed latent to predict a velocity field; after training, a class-conditional rectified-flow prior replaces the encoder for generation.
- The key constraint projects the predicted velocity onto ker A (A being the montage-related linear operator's null space), and the Gaussian source is projected at inference too, guaranteeing physically valid EEG.
- A PyTorch implementation (configs/, montageflow/, scripts/, tests/) with checkpoints on Hugging Face, using Temple University Hospital EEG corpora such as TUAB v3.0.1.
