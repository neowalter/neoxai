*MOABB Uses Cached Data Before Prefetching NEMAR (#1169)*

**简介：** MOABB优化NEMAR数据缓存，减少重复下载。

**Brief:** MOABB optimizes NEMAR dataset caching to reduce redundant downloads for BCI benchmarking.

- MOABB现在会在预取NEMAR数据集之前使用缓存数据。
- 这减少了重复下载，同时在移除缓存后保留NEMAR优先行为。

- MOABB now uses cached data before prefetching NEMAR datasets.
- This reduces redundant downloads while preserving NEMAR-first behavior after cache removal.
