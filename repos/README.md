## How to add a repo

When outreach reaches a new builder, append an item to `catalog.json` (and a card in the current `YYYY-MM.md` if present) with:

- `id`: `github:owner/name`
- `name`, `owner`, `url`, `description`
- `pushedAt` / `updatedAt` (ISO from GitHub)
- `outreach.contactedAt` (YYYY-MM-DD), `outreach.batch`, `outreach.contactedAuthor`

Do not commit issue bodies, DMs, or other private outreach text here.

## Related

- Datasets / models / methods / papers stay in their own folders.
- Raw EEG never belongs in this hub.
