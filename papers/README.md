# Papers archive

Research items from arXiv (API + `cs.HC` / `q-bio.NC` / `eess.SP` Atom), bioRxiv, medRxiv, and journal RSS (e.g. Frontiers Neuroprosthetics) after keyword filter (BCI, EEG, MEG, neural interface, EEG foundation models, …).

## Files

`papers/YYYY-MM.md` — same field set as [`../news/README.md`](../news/README.md), plus `arxiv:` when applicable.

Google Scholar is **not** a feed. Discovery uses the [arXiv API](https://info.arxiv.org/help/api/index.html) and official RSS/Atom.

## Example

```markdown
# BCI / EEG papers — 2026-08

### A foundation model for EEG decoding

- url: https://arxiv.org/abs/2608.24887
- source: arxiv-api-bci
- published: 2026-08-28T02:28:20.000Z
- arxiv: 2608.24887
- summary: Abstract excerpt, ≤400 characters.
```

These files are **link + metadata** archives, not a reprint server. Follow the publisher or arXiv license for the PDF.
